Our Tech Stack

These are the technologies we used to build our Expense Tracker project. Each technology helped us learn different parts of modern web development.

HTML5

Used to create the structure and layout of the website.

CSS3

Used for styling, spacing, colors, animations and responsive design.

JavaScript

Used to make the website interactive and dynamic.

CSS Grid

Used to create structured and responsive layouts.

Flexbox

Used for alignment, spacing and positioning elements properly.

Local Storage

Used to store expense data in the browser permanently.

We did not use any external libraries or frameworks. Everything was built from scratch using technologies we learned in class.
